# 合成材料筛选 · Grid Recipe Filter

![合成材料筛选 Logo](docs/logo.png)

由 [幼幼紫](https://github.com/uuzsx) 制作的 NeoForge 模组，可以直接在原版配方书中查找合成格里的材料可以用于哪些工作台配方。

不知道手里的材料能做什么？把材料放进背包或工作台的合成格，就能快速查看相关配方，减少翻找和搜索。

## 能做什么

- **按材料筛选配方**：支持原版材料和模组材料，也可以放入多种材料一起筛选。
- **查看未解锁配方**：未解锁的工作台配方也会显示，点击后直接在原版合成格中预览材料和产物；红色背景表示配方未解锁或材料不足。
- **保留已经放入的物品**：预览不会移动、消耗或遮挡真实物品，也不会自动解锁配方。
- **沿用原版操作**：保留配方书的搜索和分类。点击搜索框旁的“材 / M”按钮，或按 **Ctrl+G**，即可切换材料筛选。

本模组用于工作台合成配方，不包含熔炉或模组机器的加工配方。

## 下载与安装

前往 **[GitHub 下载页](https://github.com/uuzsx/grid-recipe-filter/releases/latest)**，选择与你的 Minecraft 版本对应的 `.jar` 文件，放进游戏实例的 `mods` 文件夹。

支持 **Minecraft Java 1.21.1、1.21.2、26.1.1、26.1.2、26.2、26.3**，均为 **NeoForge** 版本。每个实例只安装一个对应版本的文件，升级时移除旧版。

多人游戏中，1.21.2 和 26.x 若要查看完整的未解锁配方，服务器也需要安装本模组；仅客户端安装时仍可筛选已解锁配方。1.21.1 只需客户端安装即可查看完整配方。
